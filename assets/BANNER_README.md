# Plugin Banner Assets

## Required Files

WordPress.org requires two banner images:

1. **banner-772x250.png** - Standard banner (772x250 pixels)
2. **banner-1544x500.png** - High-DPI banner (1544x500 pixels)

## Design Guidelines

### Theme
- CF R2 / Media Storage
- Speed / Optimization / CDN
- Professional and minimal

### Style Requirements
- **Minimal design** - Clean, uncluttered
- **No excessive text** - Keep text minimal or optional
- **No gradients overload** - Subtle gradients only
- **Professional appearance** - Suitable for WordPress.org directory

### Optional Text
If including text, use minimal text:
- "Media Offloader for CF R2"
- Keep font size readable but not dominant

### Color Scheme
- Primary: CF orange (#F38020) - use sparingly
- Background: Light, neutral colors
- Text: Dark, high contrast

## Creating the Banners

### Option 1: Use Design Software
1. Create a 772x250 canvas for standard banner
2. Create a 1544x500 canvas for high-DPI banner
3. Design following the guidelines above
4. Export as PNG (24-bit, no transparency for banners)

### Option 2: Use Online Tools
- Canva (https://www.canva.com)
- Figma (https://www.figma.com)
- GIMP (free, open-source)

### Option 3: Hire a Designer
- WordPress.org has approved designers
- Ensure assets are GPL-compatible

## Technical Requirements

- **Format**: PNG
- **Color mode**: RGB
- **Standard banner**: 772x250 pixels (exact)
- **High-DPI banner**: 1544x500 pixels (exact)
- **File size**: Optimize for web (under 1MB each recommended)
- **No transparency**: Banners should have solid backgrounds
